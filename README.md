Token Launch Radar — ranks pre-token DeFi protocols by implied value from a sealed DefiLlama snapshot, with a concrete farm plan for each. The value model is derived from the snapshot itself: each category's multiple is the median market-cap-per-TVL of its live-token protocols, moved by the protocol's own seven-day growth and by how long it has run with no token. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```

The program reads the sealed snapshot, writes the ranked board to `out/board.json`, the dashboard's data to `out/data.js`, copies `dashboard/` and `screenshots/` to `out/`, and writes `out/dossier.json`. It runs twice with identical bytes. Node 22 or later, standard library only, no network.
